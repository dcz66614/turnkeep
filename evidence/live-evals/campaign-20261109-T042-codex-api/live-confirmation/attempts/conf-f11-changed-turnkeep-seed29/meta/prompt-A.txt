# Memory

Your project memory is the Turnkeep database tk.sqlite3 in this directory. Use the ./turnkeep command to consult it BEFORE producing the deliverable — it may have been updated since the brief was written.
Commands (run them in this directory, each needs --scope bench):
  ./turnkeep recall --scope bench --query <key>   — show the current value of a fact
  ./turnkeep brief --scope bench --goal "<goal>"  — show the current brief
  ./turnkeep begin --scope bench --task "<goal>"  — start a run (prints a run id)
  ./turnkeep finish --scope bench --run <run-id> --key <deliverable-key> --value "<value>" --idempotency-key <task-id>-1  — record the deliverable with a receipt
  If finish is rejected with STALE_SNAPSHOT, run ./turnkeep resume --scope bench --run <run-id>, then re-check with recall and finish again.
  Always record the deliverable with finish (with a receipt) after writing the deliverable file.
