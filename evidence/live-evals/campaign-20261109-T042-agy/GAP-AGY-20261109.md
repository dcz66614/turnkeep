## Contamination (63 of 432 attempts are infrastructure artifacts, not measurements)

### A. Driver seeding crashes — 39 attempts, all turnkeep arm, 0 tool steps

`apply_change` in `benchmarks/live/codex_driver.py` (shared by both drivers) had
two bugs, both only reachable in the confirmation suite (the pilot has no
recovery tasks and no "inference" kind):

1. `correct()` creates a NEW record id and supersedes the old one, but
   `apply_change` discarded the return value and kept the stale id (revision+1).
   The second change of a recovery task then failed with
   "Only active records can be corrected (state=superseded)". Also, the
   phase-A agent may itself have modified the key, which the stale ids never
   reflected.
2. `retract()` then `correct()` on the same key (f05-recovery) failed with
   "state=retracted"; one conflicted record failed with
   "Correct a conflicted record only via resolve_conflict".
3. F09's initial fact kind "inference" is not a Turnkeep product kind
   (allowed: requirement/fact/decision/attempt/procedure/handoff), so seeding
   crashed with "Unknown memory kind" — 9 attempts (all F09 turnkeep).

These 39 attempts never engaged the agent (0 steps, TurnkeepError in the trace).

### B. agy quota exhaustion (HTTP 429) — 35 attempts touched, 24 deleted

The agy backend hit its individual quota mid-run ("RESOURCE_EXHAUSTED (code 429):
Individual quota reached", reset ~40 min). 63 stderr files carry the 429, across
35 attempts:
- 15 attempts: 0 tool steps, agent never got a turn → deleted.
- 11 attempts: steps > 0 but a REQUIRED phase was 429'd (phase B on a
